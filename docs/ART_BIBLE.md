# NG Art Bible

## Visual target

Original pseudo-isometric dark low-fantasy CRPG art.

The game should feel dense, grounded, and readable at low resolution. The practical target is not pure tile pixel art, but detailed 2D background plates with small readable sprites, baked shadows, and sparse runtime effects.

## Style pillars

- Pseudo-isometric 2D perspective
- Detailed painterly/pixel-like backgrounds
- Muted earth palette with selective warm torchlight and cold moonlight
- Weathered stone, old timber, mud, moss, iron, bronze, parchment, pine forests
- Low-fantasy clothing and equipment over glossy heroic fantasy
- Readability over visual noise
- Original identity, not a copy of any existing game assets or exact proprietary style

## Asset generation rule

Do not prompt for exact named commercial game styles. Use this art bible instead.

## Environment prompt template

Original low-fantasy pseudo-isometric CRPG environment, fixed 3/4 isometric view, dense pre-rendered 2D background, readable walkable layout, weathered stone, old timber, mud, moss, muted earth colors, baked shadows, warm lantern light, cold rain-dark atmosphere, no characters, no text, no UI.

## Portrait prompt template

Original low-fantasy CRPG character portrait, practical medieval frontier clothing, weathered face, muted colors, painted portrait, serious grounded expression, parchment-dark background, readable silhouette, not anime, not glossy modern fantasy, not photorealistic.

## Initial area identity

### Wolfpine Road

A rain-dark frontier road through black pines and ruined imperial stones. Muddy ground, old shrine, broken wagon signs, cold gray-green atmosphere.

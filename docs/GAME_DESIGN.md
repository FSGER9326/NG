# NG Game Design

## High concept

A low-spec, party-based, pseudo-isometric CRPG set in an original dark low-fantasy borderland.

The game emphasizes companions, faction pressure, skill checks, tactical combat, exploration, and consequences. It should be extendable through new data files, dialogue files, areas, and assets.

## Main influences by function

- Classic Infinity Engine games: party exploration, companions, dense 2D areas
- Age of Decadence / Colony Ship: skill checks, hard consequences, faction routing
- Exiled Kingdoms: accessible exploration and quest structure
- Battle Brothers: grounded danger, wounds, backgrounds, mercenary mood

## Initial combat direction

Start with turn-based AP combat. Real-time-with-pause is not a first milestone.

## Core player fantasy

A small band of dangerous nobodies arrives in a starving border region and becomes entangled in village politics, old faiths, smugglers, broken imperial ruins, and desperate factions.

## First vertical slice

Wolfpine Road and Wolfpine Village should prove:

- area loading
- party movement
- NPC interaction
- dialogue choices
- quest state changes
- combat transition
- inventory item loading
- save/load later

# NG Game Wiki

Welcome to the player-facing wiki for **NG / New Game**.

This wiki is written to teach the game as it grows: the world, factions, companions, quests, mechanics, and practical play tips. It is intentionally separate from the developer docs in `docs/`.

## Current state

NG is still in early prototype. The current playable slice is **Wolfpine Road**, a small test area proving movement, dialogue, quest state, hotspots, and early pseudo-isometric presentation.

## What kind of game is NG?

NG is planned as a low-spec, pseudo-isometric, party-based CRPG set in a dark low-fantasy borderland.

The game focuses on:

- exploration of hand-authored areas
- companions with identity and opinions
- dialogue choices
- faction reputation
- quest consequences
- tactical combat
- grounded danger rather than chosen-one fantasy

## Current test path

In the current prototype:

1. Launch the game in Godot.
2. Click `@ captain_renna`.
3. Choose the work dialogue option.
4. The quest tracker should show `missing_caravan: accepted`.
5. Click `Old Road Shrine`.
6. The quest tracker should show `missing_caravan: found_wreck`.

This is not final gameplay presentation. It is the first working quest loop.

Project identity
- NG is a Godot 4 RPG project targeting a low-spec Compatibility-renderer pipeline.
- For Wolfpine visual work, preserve a modernized Infinity Engine / dark-fantasy isometric direction: painterly or pre-rendered, readable silhouettes, grounded contact shadows, and data-driven assets.
- Prefer small text-first changes. Keep game content data-driven in JSON, Markdown, GDScript, and Godot text scenes. Avoid large binary dumps unless a task explicitly requires them.

Asset status model
- planned: listed but not produced or reviewed.
- generated_candidate / external_candidate: candidate exists outside canonical acceptance or needs source/license checks.
- cleaned: file-backed production candidate exists at intended_file, but still needs visual/layout review before acceptance.
- accepted: production asset passed review and must have a matching accepted review outcome.
- rejected: asset should not be used as production art.

Important acceptance rule
- Do not mark an asset accepted only because a PNG exists.
- Accepted assets require: committed PNG at intended_file, manifest SHA256 matching the file, valid PNG header, Godot visual/layout review, and a matching accepted review outcome in data/asset_review_outcomes/.

Asset validators and tests

Main CI validation workflow

Current binary limitation in ChatGPT connector workflow
- The available GitHub connector can write text files and create blobs from inline content, but it does not expose a safe local file-path upload for multi-megabyte PNGs from /mnt/data.
- Therefore the first real PNG binary promotion should be performed from a local checkout using the checked-in helper scripts and the handoff ZIP.

Style notes for Wolfpine assets
- Fixed pseudo-isometric 3/4 CRPG camera.
- Modernized Infinity Engine / BG2 / Planescape Torment mood: painterly, grounded, dark-fantasy medieval village materials.
- Avoid clean RTS/mobile-game visuals, pixel art, readable baked text, modern materials, impossible architecture, and props that block required routes or hotspots.
- Preserve low-spec rendering expectations: simple PNG sprites, clear silhouettes, reasonable dimensions, and no unnecessary binary asset bulk.
